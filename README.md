# HTTP Server in C

A lightweight HTTP server built from scratch in C, with a focus on understanding low-level programming, networking, and the HTTP protocol.

## Project Goals

- Gain practical experience with C and manual memory management.
- Understand TCP sockets and HTTP/1.1.
- Learn and apply Test-Driven Development (TDD).
- Establish a structured development workflow using GitHub Issues, feature branches, pull requests, and continuous integration.

## Development Approach

This project follows the Red-Green-Refactor cycle of Test-Driven Development. Features are developed incrementally, starting with tests before implementing the corresponding functionality.

## Project Structure

| Directory | Purpose |
|---|---|
| `src/` | Source files and implementations |
| `include/` | Header files and interfaces |
| `tests/` | Automated tests |
| `build/` | Generated build artifacts (not tracked by Git) |

## Project Status

**Early development – Project Foundation**

The project is currently in its initial setup phase. The build system, testing environment, and CI pipeline are planned as the next steps.
